## ⚡ Быстрый запуск

### Хотите GUI (графический интерфейс)? 🎨 **РЕКОМЕНДУЕТСЯ**

#### Windows:
Дважды кликните на файл: **`run-gui.bat`**

#### Linux / macOS:
```bash
./run-gui.sh
```

### Предпочитаете консоль? 💻

#### Windows:
Дважды кликните на файл: **`run.bat`**

#### Linux / macOS:
```bash
./run.sh
```

## 🎯 Что реализовано

✅ **Управление видеоносителями**
- Каталог фильмов и игр
- Многокритериальный поиск
- Добавление/редактирование носителей
- Статистика и топ популярных

✅ **Управление клиентами**
- Регистрация с полными данными
- Система бонусов
- Черный список
- История аренд

✅ **Аренда и возврат**
- Оформление аренды с расчетом стоимости
- Возврат с учетом просрочек
- Обработка повреждений носителей
- Автоматический расчет штрафов

✅ **Система пользователей**
- 3 роли с разными правами
- Разграничение доступа
- Аутентификация

✅ **Отчеты и аналитика**
- Финансовые отчеты
- Отчеты по клиентам
- Отчеты по просрочкам
- Дашборд для руководителя

✅ **Два интерфейса**
- GUI (графический) - красиво и удобно
- Консольный - быстро и функционально

## ❓ Возникли проблемы?

### Программа не запускается?
1. Убедитесь что установлен JDK (не только JRE)
2. Проверьте что Java добавлена в PATH
3. Попробуйте запустить через командную строку вручную:
   ```bash
   javac -encoding UTF-8 -d . *.java
   java videoprokat.VideoprokatGUI
   ```

### Кириллица отображается неправильно?
Используйте скрипты запуска (`run-gui.bat` или `run-gui.sh`) - они настраивают кодировку.

### Нужна помощь?
Откройте [README.md](README.md) для подробной информации.

## 🎓 Для преподавателей и проверяющих

Этот проект демонстрирует:

**Принципы ООП:**
- ✅ **Инкапсуляция** - защищенные поля, геттеры/сеттеры с валидацией
- ✅ **Наследование** - 8 пар классов (абстрактный + реализация)
- ✅ **Полиморфизм** - работа через абстрактные типы

**Архитектурные решения:**
- Модульная структура с разделением ответственности
- Абстрактные классы как контракты
- Единообразный дизайн API

**Функциональность:**
- Полный цикл бизнес-процессов видеопроката
- Система прав доступа
- Два типа интерфейса (GUI и консольный)

Подробнее см. [OOP_PRINCIPLES.md](OOP_PRINCIPLES.md)
