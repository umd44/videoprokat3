# Видеопрокат - Демонстрация Концепций ООП

Проект представляет собой систему управления видеопрокатом, реализованную на Java и C++, с демонстрацией всех основных концепций объектно-ориентированного программирования.

## Структура Проекта

### Java Файлы
- **Базовые абстрактные классы:**
  - `Client.java` - абстрактный класс клиента
  - `VideoCarrier.java` - абстрактный класс видеоносителя
  - `Rental.java` - абстрактный класс аренды
  - Другие базовые классы системы

- **Производные классы (для демонстрации наследования):**
  - `PremiumClient.java` - премиальный клиент (наследует Client)
  - `CorporateClient.java` - корпоративный клиент (наследует Client)
  - `DVDCarrier.java` - DVD носитель (наследует VideoCarrier)
  - `BluRayCarrier.java` - BluRay носитель (наследует VideoCarrier)

- **Интерфейсы:**
  - `Discountable.java` - интерфейс для объектов со скидками
  - `Notifiable.java` - интерфейс для отправки уведомлений

- **Демонстрация:**
  - `InheritanceDemo.java` - демонстрация всех концепций ООП

### C++ Файлы
- **Базовые классы (в директории videoprokat/):**
  - `Client.hpp/cpp` - базовый класс клиента
  - `VideoCarrier.hpp/cpp` - базовый класс видеоносителя
  - И другие классы системы

- **Производные классы:**
  - `PremiumClient.hpp/cpp` - премиальный клиент
  - `DVDCarrier.hpp/cpp` - DVD носитель
  - `BluRayCarrier.hpp/cpp` - BluRay носитель

- **Абстрактный класс:**
  - `PaymentProcessor.hpp/cpp` - абстрактный класс обработки платежей

- **Демонстрация:**
  - `InheritanceDemo.cpp` - демонстрация всех концепций ООП

## Реализованные Концепции ООП

### Общие для C++ и Java:

#### 1. Производные классы
- ✅ **PremiumClient** - клиент с системой лояльности и скидками
- ✅ **CorporateClient** - корпоративный клиент с корпоративными скидками
- ✅ **DVDCarrier** - DVD носитель с поддержкой субтитров
- ✅ **BluRayCarrier** - BluRay носитель с поддержкой 4K и HDR

#### 2. Модификатор protected
- ✅ В `Client`: поля `m_clientId`, `m_firstName`, `m_depositBalance` и др.
- ✅ В `VideoCarrier`: поля `m_inventoryNumber`, `m_title`, `m_rentalPricePerDay` и др.
- ✅ Защищенные методы: `updateLoyalty()`, `calculateCorporateDiscount()`, `applyDVDDiscount()`

#### 3. Перегрузка методов базового класса

**С вызовом базового метода:**
- `PremiumClient::addToDeposit()` - вызывает `super.addToDeposit()` и добавляет начисление бонусов
- `BluRayCarrier::markAsAvailable()` - вызывает базовый метод и добавляет логирование

**Без вызова базового метода:**
- `PremiumClient::blockDepositFunds()` - полностью переопределяет логику с применением скидки
- `BluRayCarrier::markAsRented()` - полностью новая реализация

#### 4. Виртуальные функции (полиморфизм)

**Демонстрация:**
- Вызов через указатель базового класса на объект производного класса
- Вызов виртуальной функции через не виртуальную функцию базового класса:
  - `Client::processTransaction()` вызывает виртуальную `addToDeposit()`
  - `PaymentProcessor::executePayment()` вызывает виртуальную `processPayment()`
- Демонстрация изменения поведения, если функция не виртуальная

#### 5. Клонирование объектов
`DVDCarrier` поддерживает два типа клонирования:

**Поверхностное клонирование:**
```java
DVDCarrier* shallowClone = original->shallowClone();
```
- Копирует указатель на вектор субтитров
- Изменения в клоне влияют на оригинал

**Глубокое клонирование:**
```java
DVDCarrier* deepClone = original->deepClone();
```
- Создает новый вектор субтитров
- Клон полностью независим от оригинала

#### 6. Вызов конструктора базового класса
Все производные классы демонстрируют вызов конструктора базового класса:
```cpp
PremiumClient::PremiumClient(...)
    : Client(clientId, firstName, lastName, phoneNumber),
      m_discountPercentage(discountPercentage),
      ...
```

#### 7. Абстрактные классы
- **Java**: `Client`, `VideoCarrier`, `Rental` - с абстрактными методами
- **C++**: `PaymentProcessor` - с чисто виртуальными функциями

### Специфично для C++:

#### 8. Перегрузка оператора присваивания
`PremiumClient` имеет перегруженный оператор присваивания для присваивания базового класса производному:
```cpp
PremiumClient& operator=(const Client& base);
```

#### 9. Удаление конструктора копирования
Для некоторых классов конструктор копирования запрещен:
```cpp
PremiumClient(const PremiumClient&) = delete;
BluRayCarrier(const BluRayCarrier&) = delete;
```

#### 10. Виртуальный деструктор
Все базовые классы имеют виртуальный деструктор:
```cpp
virtual ~Client();
virtual ~VideoCarrier();
virtual ~PaymentProcessor();
```
Это обеспечивает корректное удаление объектов производных классов через указатель на базовый класс.

### Специфично для Java:

#### 11. Интерфейсы
- `Discountable` - интерфейс для объектов, поддерживающих скидки
- `Notifiable` - интерфейс для отправки уведомлений

#### 12. Множественное наследование
`PremiumClient` демонстрирует множественное наследование:
```java
public class PremiumClient extends Client implements Discountable, Notifiable
```
- Наследует от абстрактного класса `Client`
- Реализует интерфейсы `Discountable` и `Notifiable`

## Архитектура Системы

Система видеопроката состоит из следующих компонентов:

- **Client** - управление клиентами и их депозитами
- **VideoCarrier** - управление видеоносителями (DVD, BluRay, и др.)
- **Catalog** - каталог доступных носителей
- **Rental** - управление арендой
- **RentalManager** - обработка создания и возврата аренды
- **FinancialCalculator** - расчет стоимости и залогов
- **ReportGenerator** - генерация отчетов
- **PaymentProcessor** - обработка платежей (C++)

## Особенности Реализации

### Виртуальные функции
Все методы, которые могут быть переопределены в производных классах, объявлены как виртуальные. Это позволяет использовать полиморфизм для работы с объектами через указатели/ссылки на базовый класс.

### Protected члены
Использование protected позволяет производным классам напрямую работать с данными базового класса, но скрывает их от внешнего кода.

### Клонирование
Реализованы два типа клонирования для демонстрации разницы между поверхностным и глубоким копированием объектов.

### Множественное наследование
В Java реализовано через интерфейсы, что позволяет классу наследовать поведение от нескольких источников.
