# Информационная Система Видеопроката

Консольная демонстрационная программа для моделирования работы информационной системы видеопроката на Java.

## Описание

Проект представляет собой полнофункциональную систему управления видеопрокатом с использованием объектно-ориентированного подхода. Система реализована с помощью абстрактных базовых классов и их конкретных реализаций, демонстрируя принципы ООП, полиморфизма и инкапсуляции.

## Архитектура системы

Система построена на основе следующих компонентов:

### Основные модули

1. **Модуль управления пользователями**
   - `User` (абстрактный) / `UserReal` (реализация)
   - Поддержка трех ролей: Оператор, Старший оператор, Администратор
   - Система разграничения прав доступа

2. **Модуль учета клиентов**
   - `Client` (абстрактный) / `ClientReal` (реализация)
   - Полная информация о клиентах: ФИО, паспорт, адрес, контакты
   - Система бонусов и черный список
   - Управление депозитами

3. **Модуль учета видеоносителей**
   - `VideoCarrier` (абстрактный) / `VideoCarrierReal` (реализация)
   - Полная информация о носителях: название, жанр, год выпуска, режиссер
   - Возрастные рейтинги, описание, статусы
   - Отслеживание количества аренд

4. **Модуль каталога**
   - `Catalog` (абстрактный) / `CatalogReal` (реализация)
   - Многокритериальный поиск по различным параметрам
   - Статистика и аналитика
   - Топ популярных носителей

5. **Модуль управления арендой**
   - `Rental` (абстрактный) / `RentalReal` (реализация)
   - `RentalManager` (абстрактный) / `RentalManagerReal` (реализация)
   - Создание и обработка аренд
   - Обработка возвратов с учетом просрочек
   - Обработка повреждений носителей

6. **Модуль финансовых расчетов**
   - `FinancialCalculator` (абстрактный) / `FinancialCalculatorReal` (реализация)
   - Расчет стоимости аренды
   - Расчет залогов
   - Расчет штрафов за просрочку

7. **Модуль отчетности**
   - `ReportGenerator` (абстрактный) / `ReportGeneratorReal` (реализация)
   - Финансовые отчеты
   - Отчеты по клиентам
   - Отчеты по популярности носителей
   - Дашборд для руководителя

## Функциональность

### Система пользователей и прав доступа

**Оператор (базовый уровень):**
- Поиск носителей в каталоге
- Оформление аренды и возврата
- Просмотр информации о клиентах
- Регистрация новых клиентов
- Прием платежей

**Старший оператор (расширенный уровень):**
- Все права оператора
- Редактирование информации о носителях
- Изменение статусов клиентов
- Применение скидок
- Просмотр финансовых отчетов
- Управление штрафами и залогами

**Администратор (полный доступ):**
- Все права старшего оператора
- Управление пользователями
- Редактирование справочников
- Доступ ко всем отчетам
- Списание и восстановление носителей
- Настройка параметров системы

### Основные операции

1. **Регистрация клиентов** с полными данными:
   - ФИО, дата рождения
   - Паспортные данные
   - Контактная информация (телефон, email)
   - Адрес регистрации
   - Система бонусов
   - Статус (активен/заблокирован)

2. **Учет видеоносителей** с детальной информацией:
   - Инвентарный номер
   - Название фильма/игры
   - Тип носителя (DVD, Blu-ray, игровая приставка)
   - Жанр
   - Год выпуска
   - Режиссер/разработчик
   - Возрастной рейтинг (0+, 6+, 12+, 16+, 18+)
   - Описание
   - Стоимость проката и полная стоимость
   - Статус (доступен, арендован, на реставрации, списан)

3. **Многокритериальный поиск** носителей:
   - По названию (полнотекстовый поиск)
   - По жанру
   - По режиссеру/разработчику
   - По году выпуска
   - По типу носителя
   - По возрастному рейтингу
   - По статусу доступности

4. **Оформление аренды** с автоматическим расчетом:
   - Выбор клиента и носителей
   - Указание срока аренды
   - Автоматический расчет стоимости и залога
   - Изменение статусов носителей
   - Начисление бонусов клиенту

5. **Обработка возврата** с различными сценариями:
   - Возврат в срок без проблем
   - Возврат с просрочкой (автоматический расчет штрафа)
   - Возврат с повреждениями (незначительные/критические)
   - Обработка утери носителя
   - Возврат залога с учетом всех удержаний

6. **Генерация отчетов**:
   - Финансовые отчеты за период
   - Отчеты по клиентам
   - Отчеты по популярности носителей
   - Отчеты по просрочкам
   - Статистика каталога
   - Дашборд текущего дня для руководителя

## Особенности реализации

### Паттерны проектирования

- **Template Method** - использование абстрактных классов с определением интерфейса
- **Strategy** - различные стратегии расчета стоимости и штрафов
- **Repository** - каталог как хранилище носителей

### ООП принципы

- **Инкапсуляция** - protected поля, публичные методы доступа
- **Наследование** - абстрактные классы и их реализации
- **Полиморфизм** - работа через интерфейсы абстрактных классов
- **Абстракция** - выделение общих черт в абстрактные классы

### Обработка различных сценариев

- Возврат в срок
- Просрочка возврата (с автоматическим расчетом штрафа)
- Незначительные повреждения (перевод в реставрацию)
- Критические повреждения/утеря (списание)

## Расширение функциональности

Систему можно расширить следующими возможностями:

1. **База данных** - интеграция с СУБД для постоянного хранения
2. **Сетевой режим** - клиент-серверная архитектура
3. **GUI** - графический интерфейс пользователя
4. **Бронирование** - предварительное бронирование носителей
5. **Уведомления** - SMS/Email уведомления клиентам
6. **Скидки** - гибкая система скидок и акций
7. **Аналитика** - расширенная аналитика и прогнозирование
