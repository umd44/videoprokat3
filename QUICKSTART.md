# Быстрый старт - Система Видеопроката

## 🚀 Запуск программы

### Windows
1. Откройте папку с проектом
2. Дважды кликните на файл `run.bat`
3. Подождите завершения компиляции

### Linux / macOS
1. Откройте терминал в папке проекта
2. Выполните команду: `./run.sh`
3. Подождите завершения компиляции

## 🔐 Вход в систему

При запуске программа попросит ввести логин и пароль.

### Доступные учетные записи:

| Логин    | Пароль | Роль                | Права доступа |
|----------|--------|---------------------|---------------|
| operator | 1234   | Оператор           | Базовые операции (поиск, аренда, возврат) |
| senior   | 5678   | Старший оператор   | + редактирование данных, отчеты |
| admin    | admin  | Администратор      | Полный доступ ко всем функциям |

**Рекомендуется начать с:** `admin` / `admin` для доступа ко всем возможностям системы.

## 📋 Главное меню

После входа вы увидите главное меню с пунктами:

```
1. Управление видеоносителями  - просмотр, поиск, добавление фильмов
2. Управление клиентами        - регистрация, поиск, блокировка
3. Оформление аренды           - создание новой аренды
4. Обработка возврата          - возврат с расчетом штрафов
5. Отчеты и статистика         - различные отчеты
6. Управление пользователями   - только для администраторов
0. Выход из системы
```

## 🎬 Типичный сценарий работы

### 1. Просмотр каталога
```
Главное меню → 1 → 1 (Просмотр всех носителей)
```
Вы увидите список всех доступных фильмов с информацией.

### 2. Поиск фильма
```
Главное меню → 1 → 2 (Поиск носителей)
```
Выберите критерий поиска (название, жанр, режиссер и т.д.)

### 3. Регистрация нового клиента
```
Главное меню → 2 → 3 (Регистрация нового клиента)
```
Введите данные клиента по запросу системы.

### 4. Оформление аренды
```
Главное меню → 3 (Оформление аренды)
```

Шаги:
1. Введите ID клиента (например: 1001 или 1002 - тестовые клиенты уже есть)
2. Введите инвентарный номер носителя (например: 2001, 2002, 2003...)
3. Для добавления еще носителей введите их номера
4. Введите 0 для завершения выбора
5. Укажите количество дней аренды
6. Проверьте расчет и подтвердите

### 5. Обработка возврата
```
Главное меню → 4 (Обработка возврата)
```

Шаги:
1. Просмотрите список активных аренд
2. Введите ID аренды
3. Укажите количество дней просрочки (0 если в срок)
4. Укажите наличие повреждений
5. При повреждениях выберите носитель и тип повреждения

### 6. Просмотр отчетов
```
Главное меню → 5 (Отчеты и статистика)
```

Доступные отчеты:
- Финансовый отчет
- Отчет по клиентам
- Топ популярных носителей
- Отчет по просрочкам
- Дашборд текущего дня (только для администратора)

## 💡 Полезные советы

1. **Навигация**: Для возврата в предыдущее меню всегда используйте `0`

2. **Разграничение прав**: Попробуйте войти под разными пользователями, чтобы увидеть разницу в доступных функциях

3. **Поиск**: Используйте различные критерии поиска для эффективного нахождения нужных данных

4. **Отчеты**: Раздел отчетов содержит полную аналитику по работе системы

5. **Просрочки**: При оформлении возврата система автоматически рассчитывает штрафы по формуле: (Тариф × 2) × Дни просрочки

6. **Повреждения**:
   - Незначительное повреждение → носитель отправляется на реставрацию
   - Критическое повреждение → носитель списывается

## ❓ Частые вопросы

**Q: Программа не запускается**
A: Убедитесь, что установлен Java Development Kit (JDK) версии 8 или выше

**Q: Русские буквы отображаются неправильно**
A: Используйте скрипты `run.bat` (Windows) или `run.sh` (Linux/macOS) - они настраивают кодировку автоматически

**Q: Как сбросить данные?**
A: Перезапустите программу - все изменения сохраняются только в памяти во время сеанса

**Q: Можно ли добавить свои данные?**
A: Да, используйте соответствующие пункты меню (требуются права старшего оператора или администратора)
