# Руководство по GUI версии системы видеопроката

## 🚀 Быстрый запуск

### Windows
Дважды кликните на файл `run-gui.bat`

### Linux / macOS
В терминале выполните:
```bash
./run-gui.sh
```

## 📋 Экран входа

После запуска откроется окно авторизации с заголовком **"Система видеопроката"**.

### Доступные учетные записи:

| Логин    | Пароль | Роль                | Описание |
|----------|--------|---------------------|----------|
| operator | 1234   | Оператор           | Базовые операции |
| senior   | 5678   | Старший оператор   | Расширенные права |
| admin    | admin  | Администратор      | Полный доступ |

**Совет:** Для первого запуска рекомендуется войти как `admin` / `admin` для доступа ко всем функциям.

## 🏠 Главное меню

После входа вы увидите главное меню с 9 кнопками:

```
┌─────────────────────┬─────────────────────┬─────────────────────┐
│  📀 Видеоносители  │   👥 Клиенты       │  🎬 Оформление      │
│                     │                     │     аренды          │
├─────────────────────┼─────────────────────┼─────────────────────┤
│  ↩️ Обработка       │   📊 Отчеты        │  👤 Пользователи    │
│    возврата         │                     │  (только admin)     │
├─────────────────────┼─────────────────────┼─────────────────────┤
│  ℹ️ О системе       │                     │                     │
```

В верхней части окна отображается:
- **Слева:** ФИО текущего пользователя и роль
- **Справа:** Кнопка "Выход" для выхода из системы

## 📀 Управление видеоносителями

### Просмотр каталога

Кликните на кнопку **"📀 Видеоносители"** → откроется окно с таблицей всех носителей.

**Столбцы таблицы:**
- № - инвентарный номер
- Название - название фильма/игры
- Тип - DVD / Blu-ray
- Жанр - категория контента
- Год - год выпуска
- Режиссер - автор контента
- Рейтинг - возрастной рейтинг (0+, 6+, 12+, 16+, 18+)
- Цена/день - стоимость проката за сутки
- Статус - текущее состояние носителя

### Поиск носителей

В окне видеоносителей нажмите кнопку **"Поиск"**:

1. Выберите критерий поиска из списка:
   - По названию
   - По жанру
   - По режиссеру
   - По году
   - По типу носителя
   - Только доступные

2. Введите значение для поиска

3. Просмотрите результаты в отдельном окне

### Добавление нового носителя

*Требуются права старшего оператора или администратора*

1. В окне видеоносителей нажмите **"Добавить носитель"**

2. Заполните форму:
   - Название
   - Тип (DVD/Blu-ray)
   - Жанр
   - Год выпуска
   - Режиссер
   - Возрастной рейтинг (0+, 6+, 12+, 16+, 18+)
   - Цена проката (руб/день)
   - Полная стоимость
   - Описание

3. Нажмите **"Сохранить"**

### Просмотр статистики

Нажмите кнопку **"Статистика"** чтобы увидеть:
- Общее количество носителей
- Доступных носителей
- Арендованных носителей
- На реставрации
- Списанных
- Топ-5 популярных носителей

## 👥 Управление клиентами

### Просмотр базы клиентов

Кликните на кнопку **"👥 Клиенты"** → откроется окно с таблицей клиентов.

**Столбцы таблицы:**
- ID - уникальный номер клиента
- ФИО - полное имя
- Телефон - контактный номер
- Email - электронная почта
- Бонусы - накопленные бонусные баллы
- Статус - Активен / БЛОКИРОВАН

### Регистрация нового клиента

1. В окне клиентов нажмите **"Регистрация клиента"**

2. Заполните форму:
   - Фамилия
   - Имя
   - Отчество
   - Телефон
   - Email (опционально)
   - Серия паспорта
   - Номер паспорта
   - Дата рождения (ГГГГ-ММ-ДД)
   - Адрес

3. Нажмите **"Сохранить"**

4. Система выдаст ID нового клиента

### Блокировка/Разблокировка клиента

*Требуются права старшего оператора или администратора*

1. Нажмите **"Блокировка/Разблокировка"**

2. Введите ID клиента

3. Система покажет информацию о клиенте и текущий статус

4. Подтвердите действие:
   - Для активного клиента: введите причину блокировки
   - Для заблокированного: подтвердите разблокировку

## 🎬 Оформление аренды

1. Кликните на кнопку **"🎬 Оформление аренды"**

2. Система выведет информационное окно с описанием функции

3. Для полной функциональности используйте консольную версию или следуйте подсказкам

**Основные шаги:**
- Ввести ID клиента
- Выбрать носители по инвентарным номерам
- Указать срок аренды
- Подтвердить оформление

## ↩️ Обработка возврата

1. Кликните на кнопку **"↩️ Обработка возврата"**

2. Если есть активные аренды, система покажет список

3. Выберите аренду для обработки возврата

4. Укажите:
   - Количество дней просрочки (если есть)
   - Наличие повреждений
   - Тип повреждения (незначительное/критическое)

5. Система автоматически рассчитает штрафы и компенсации

## 📊 Отчеты и статистика

Кликните на кнопку **"📊 Отчеты"** и выберите тип отчета:

### 1. Финансовый отчет
- Доходы от проката
- Доходы от штрафов
- Итоговая финансовая информация

### 2. Отчет по клиентам
- Список всех клиентов
- Статистика по каждому клиенту
- Информация о бонусах и депозитах

### 3. Топ популярных носителей
- Список самых арендуемых носителей
- Количество аренд для каждого
- Доходность

### 4. Отчет по просрочкам
- Список текущих просроченных аренд
- Информация о клиентах
- Размер штрафов

### 5. Дашборд текущего дня
*Только для администраторов*

- Количество активных аренд
- Количество просроченных возвратов
- Доход за день
- Количество обслуженных клиентов
- Общая статистика носителей

## 👤 Управление пользователями

*Только для администраторов*

Кликните на кнопку **"👤 Пользователи"** чтобы увидеть:
- Список всех пользователей системы
- Их логины и роли
- Статус (активен/неактивен)

## ℹ️ О системе

Кликните на кнопку **"ℹ️ О системе"** для просмотра информации:
- Название системы
- Версия
- Краткое описание
- Авторские права

## 🎯 Советы по использованию

1. **Разграничение прав:** Войдите под разными пользователями (operator, senior, admin) чтобы увидеть разницу в доступных функциях

2. **Таблицы:** Используйте прокрутку для просмотра больших таблиц

3. **Поиск:** Воспользуйтесь функцией поиска для быстрого нахождения нужных данных

4. **Формы:** Все обязательные поля должны быть заполнены для сохранения

5. **Отчеты:** Отчеты отображаются в отдельных окнах с возможностью прокрутки

## 🔧 Требования к системе

- **Java:** JDK 8 или выше
- **ОС:** Windows, Linux, macOS
- **Разрешение экрана:** минимум 1200x800
- **RAM:** минимум 512 MB свободной памяти

## ❓ Частые вопросы

**Q: Окно не открывается**
A: Убедитесь что установлен JDK и Java правильно настроена в PATH

**Q: Текст отображается неправильно**
A: Используйте скрипты запуска (run-gui.bat/run-gui.sh) - они настраивают кодировку

**Q: Как выйти из программы?**
A: Нажмите кнопку "Выход" в главном меню или закройте окно

**Q: Данные сохраняются?**
A: В текущей версии данные хранятся только в памяти. После перезапуска программы данные сбрасываются до начальных

**Q: Можно ли изменить размер окна?**
A: Да, окна можно изменять в размере, двигать и максимизировать
